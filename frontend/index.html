How the learning loop works
  1. When you select one answer in a comparison, the selected answer is a positive example and the alternative is a negative example.
  2. Explicit feedback such as “more practical examples” is stored as a user-confirmed preference.
  3. A local Logistic Regression model is trained only after enough real comparisons are collected.
  4. The model's measured tendencies guide future responses for relevant categories. The current prompt always takes priority.

Training currently requires at least 10 A/B comparisons. Small datasets are not sufficient evidence of a reliable preference model.

How requests are routed

The Personalization Agent classifies your task, retrieves matching memories and assembles a compact context. The selected providers receive that context in parallel. Image inputs require a vision-capable provider model; text-only providers are reported as unavailable for image analysis rather than silently ignoring the image.
